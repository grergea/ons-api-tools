자동화 시 유의

테스트 도메인에서 호출해 확인한 동작입니다.

  • 인증서 연결/해제와 HTTPS ON/OFF는 각각 사전 배포(Staging)와 최종 배포의 2단계입니다.
  • 인증서 최종 배포가 200이어도 연결이 반영되기까지 약 5초가 걸립니다. 그 사이에 HTTPS ON을 사전 배포하면 SSL mapping not found(E500)가 나므로, 인증서 목록에 연결이 보인 뒤에 호출합니다.
  • HTTPS 사전 배포 직후 최종 배포는 staging config status is not success(A404)로 한 번 거부될 수 있습니다. 취소 없이 20초쯤 뒤 다시 호출하면 통과합니다(실측 21초).
  • 인증서 최종 배포도 사전 배포 직후에는 Pre-deployment has not been completed로 거부될 수 있어, 스크립트는 20초 간격으로 최대 6회 재시도합니다.
  • HTTPS 최종 배포가 200이어도 https_enabled는 약 20초 뒤에 true로 바뀝니다. 그 사이에도 엣지는 이미 인증서를 응답하므로, 실패 판단은 잠시 기다린 뒤에 합니다.
  • 사전 배포가 걸린 상태에서 다시 사전 배포하면 It is already pre-deployed(E500)입니다. 다시 하려면 먼저 취소합니다.
  • HTTPS 사전 배포를 취소해도 https_enabled, 443 응답, 인증서 연결은 이전 그대로입니다.
  • 사전 배포가 없을 때 취소나 최종 배포를 호출하면 has no staging config history(A404)가 나옵니다. 취소 후에도 도메인 이력의 마지막 항목은 pre-deploy로 남아, 이력만으로는 대기 여부를 알 수 없습니다.
